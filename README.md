# Hit the Road, Dude · Whose Pond?

A playable, animated philosophy game about fishing, ownership, shared natural resources, and giving back.

Open index.html in a browser. No installation or build required.

Cast and reel with Space or the buttons. Choose responses with 1, 2, or 3. P or Escape pauses. Sound is optional.

An unofficial fictional encounter inspired by the “Hit the road, dude” meme. Dialogue is invented, not a transcript or statement of the real people’s views.
